入れ方

ダウンロードもインストーラーも要りません。Claude Code に一言お願いするだけです。

「こえタイプを入れて」

Claude デスクトップアプリの Code タブ に貼り付けてください。
アプリの取得から設定まで、最後まで付き添って進めてくれます。所要 10 分ほどです。

セキュリティの警告は出ません。 ブラウザではなくコマンド経由で取得するため、「開発元を検証できません」の画面は表示されません。

できること

話し言葉が消える「えーと」「あのー」が消えて、そのまま送れる文章になります。
言葉を覚える一度直した表記は次から間違えません。人名・商品名の登録に。
長くても平気10分喋っても10秒ほどで文字になります。上限は30分。
直前の3件が残るメニューの「結果をコピー」に直前3件が本文つきで並びます。選べばその全文がコピーできます。

使い方

  1. 文字を入れたい場所をクリックメモ、メール、Instagramの投稿欄など、どこでも構いません。
  2. fnキーを1回押して、「ポン」と鳴ってから喋るfnはキーボードの左下の角、🌐マークのキーです。
  3. もう一度fnキーを押す数秒後、整えられた文章がカーソル位置に入ります。
「ポン」と鳴ってから喋ってください。 押した直後はまだマイクが開いておらず、話し始めの言葉が切れてしまいます。

② GeminiのAPIキー

文字起こしと清書は Google の Gemini が行います。無料の範囲で足ります。

  1. aistudio.google.com/apikey を開くGoogleアカウントでログインします。
  2. 「API キーを作成」を押す
  3. 「＋ プロジェクトを作成」を選ぶここが最重要です。下の注意をお読みください。
  4. 出てきたキーをコピーして貼るClaude Code が本当に使えるキーか確かめてから保存します。
すでにあるプロジェクトを選ばないでください。 支払い情報が紐づいたプロジェクトを選ぶと無料枠が使えず、動きません。 しかも見た目ではキーが作れたように見えるため気づけません。 必ず「＋ プロジェクトを作成」を選んでください。

お金と安心のこと

アプリ無料です。受講生の方はご自由にお使いください。
Gemini無料枠で足ります。1日500回まで使えます。長さではなく回数で数えるので、10分喋っても1回です。
勝手に課金されないかされません。支払い情報を登録していないため、枠を使い切ってもエラーになるだけです。
音声はどこへGoogle の Gemini にだけ送られます。作者のサーバーは通りません。
設定の保存先ご自身のMacの中だけです。APIキーも外部には送られません。
喋った内容の扱い無料枠で使う場合、送った音声と文章はGoogleの製品改善（AIの学習を含む）に使われることがあり、担当者が読むことがあります。Googleの規約に「機密情報・個人情報を無料のサービスに送らないでください」と書かれています。お客様の氏名・連絡先や、外に出せない話は喋らないでください。
（有料で使う場合は学習に使われません。無料枠のままで足りるので、ふだんは無料のままで構いません）

うまくいかないとき

Claude Code に「こえタイプが動かない」と言えば、記録を読んで原因を調べてくれます。

fnキーを押しても何も起きない

「入力監視」の許可が入っていない可能性が高いです。Claude Code に「こえタイプが動かない」と伝えてください。設定画面を開いて確認してくれます。

喋ったのに文字が入らない

マイクが別のものになっていることがあります。メニューバーのこえタイプのアイコンを押し、「マイク」から選び直してください。AirPodsをお使いの場合は本体のマイクに切り替えると安定します。

AirPodsだと声が入らない

AirPodsはマイクを使う瞬間に通話モードへ切り替わる仕組みで、そのとき音が途切れたり拾えなかったりします。メニューから「MacBook〜のマイク」を選んでください。AirPodsは音を聴く方に使えます。

話し始めの言葉が切れる

「ポン」と鳴ってから喋ってください。押した直後の0.3秒ほどはまだマイクが開いていません。

「無料枠を使い切りました」と出た

枠が戻るのは日本時間の夕方（16〜17時ごろ）です。翌朝ではありません（Googleは太平洋時間の0時にリセットするため）。キーに問題はありません。別のモデルへ自動で切り替わるので、それまでも続けて使えることが多いです。

固有名詞がいつも間違って変換される

メニューバーのアイコン →「言葉を覚えさせる…」に、1行1件で まちがい、正しい表記 と書いて保存してください。区切りは読点でかまいません。次からは必ず正しくなります。

WindowsやIntel Macでも使えますか

現時点では使えません。Apple Silicon（M1以降）のMac専用です。Windows版は準備中です。
